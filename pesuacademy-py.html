pesuacademy.pesuacademy

PESU Academy API Client.

class pesuacademy.pesuacademy.PESUAcademy(client: _PesuScraper)

Bases: object

The main, user-facing class to interact with PESU Academy.

An instance of this class represents a single authenticated session and provides asynchronous methods to fetch academic data.

async close() → None

Closes the network session gracefully.

This should always be called when you are finished with the session to release resources.
